# Canvas Pilot feature demonstration checklist

Use one **Slides + Presenter** layout throughout: build it, refine it, exchange
it with other applications, then send it to a device. This is an operation list,
not a narration script. Tick off each item while recording.

## Before recording

- [ ] Prepare a reference image of a stage or screen layout.
- [ ] Have simple rectangle layouts ready in Illustrator, Figma and draw.io.
- [ ] Prepare a PPTX or DXF file for file import.
- [ ] Have a Midra or the supported Aquilon emulator ready, with sources already routed.
- [ ] Choose a folder for the demo project and exports.

## 1. Start a project

- [ ] Start a new project.
- [ ] Show the default Slides and Presenter layers.
- [ ] Open Output format: show presets and custom dimensions.
- [ ] Use 1920 × 1080 for the demonstration.
- [ ] Save the project with a recognizable name.

## 2. Position the layers

- [ ] Select a layer from the canvas, then from the layer list.
- [ ] Drag it and resize it using the handles.
- [ ] Toggle aspect-ratio locking and demonstrate the difference.
- [ ] Enter an exact layer width and height.
- [ ] Nudge with arrow keys, then Shift-arrow.
- [ ] Open **Measure position from**: switch between a corner and the center.
- [ ] Show that changing the measurement reference does not move the layer.
- [ ] Enable a different layer measurement point and demonstrate one precise placement.
- [ ] Undo and redo a change.

## 3. Align and resize together

- [ ] Select both layers using Shift-click or a selection box.
- [ ] Move them together.
- [ ] Demonstrate snapping to guides or another layer.
- [ ] Align one layer to the screen, then align against another layer.
- [ ] Demonstrate **Same handles** resizing.
- [ ] Demonstrate **Mirror horizontally**, then **Opposite handles**.
- [ ] Undo between examples so the layout stays understandable.

## 4. Organize the project

- [ ] Add a third layer and rename it.
- [ ] Create a folder and drag layers into it.
- [ ] Collapse and expand the folder.
- [ ] Select the folder's layers together.
- [ ] Toggle visibility and locking.
- [ ] Reorder overlapping layers to show stacking.
- [ ] Return to a clean Slides + Presenter arrangement.

## 5. Use a reference image

- [ ] Drop the prepared image into the application.
- [ ] Adjust its opacity and display placement.
- [ ] Show outline-only layer display over the reference.
- [ ] Position the layers against the reference.
- [ ] Zoom around the pointer, pan, then use **Fit screen**.
- [ ] Use **Zoom to selection**.
- [ ] Hide the reference when finished.

## 6. Show source formats and cropping

- [ ] Open the Presenter layer's properties.
- [ ] Show the distinction between source dimensions, usable input and final layer size.
- [ ] Apply an asymmetric input crop.
- [ ] Double-click the layer to adjust its crop visually.
- [ ] Zoom and reposition the content while the visible layer box stays fixed.
- [ ] Show the faded cropped-out area.
- [ ] Align the content inside the box.
- [ ] Demonstrate **Recenter**, then **Reset crop**.
- [ ] Undo back to a useful presenter framing.

## 7. Bring geometry in from other applications

- [ ] Copy a simple layout from Illustrator and paste into Canvas Pilot.
- [ ] Show destination mapping and the before/after geometry.
- [ ] Demonstrate position-only versus position-and-size import.
- [ ] Show the outline-inclusion option using Illustrator's stroked rectangles.
- [ ] Apply, then undo.
- [ ] Briefly repeat copy/paste from Figma and draw.io.
- [ ] Drop the prepared PPTX or DXF file into the window.
- [ ] Show page/slide selection if applicable, map the rectangles and apply.

## 8. Export and reopen

- [ ] Open the export format selector to show the available formats.
- [ ] Export the whole layout as SVG.
- [ ] Export only the selected layer.
- [ ] Open one export in its destination application.
- [ ] Save the Canvas Pilot project.
- [ ] Reopen it to show that editable settings and reference images are retained.

## 9. Connect to a screen processor

- [ ] Open device connection settings and connect.
- [ ] Show detected screens and layers.
- [ ] Load a device layer into the editor.
- [ ] Show its saved device destination mapping.
- [ ] Make a visible position or size change locally.
- [ ] Select Preview and review the exact changes.
- [ ] Send and show the resulting device layout.
- [ ] Show the bottom **Send** and **Load** controls.
- [ ] Demonstrate Selected or Folder transfer scope.
- [ ] Briefly show the two sizing strategies.
- [ ] If both devices are available, repeat a short load/edit/send sequence on the other family.

## 10. Use device input previews

- [ ] Enable an input preview on a layer.
- [ ] Capture a still and use it to demonstrate cropping real content.
- [ ] Adjust crop-guide opacity.
- [ ] Enable timed refresh briefly, then pause it.
- [ ] Show importing a snapshot as a fixed reference image.

## 11. Finish

- [ ] Briefly show themes and snapping preferences.
- [ ] Restore the clean finished layout.
- [ ] Fit the screen and save the project.

Leave the unfinished Midra fill/aspect modes, future adapters and multiple-screen
projects out of the feature demonstration. This checklist covers implemented
workflows as of 2026-11-16. Aquilon support is scoped to standalone AQL Cmax 6.2.x,
validated on the 6.2.79 emulator; describe emulator footage accordingly.

For detailed controls, see the [advanced guide](guide/overview.md).
