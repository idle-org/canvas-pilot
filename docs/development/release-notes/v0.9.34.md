# Canvas Pilot v0.9.34

This release adds installable theme packs, faster layer layout and crop controls,
and clearer mapping, snapping and folder interactions.

- Theme ZIP packs can be installed, updated and removed from Appearance settings.
  Included downloads: Tokyo Night, Catppuccin Mocha, Detroit: Become Human and
  Minecraft Overworld. The picker stays open for comparison; clicking High Contrast
  again restores the previous theme. High Contrast crop-helper coordinates are fixed.
- Language pack contents are collapsible. The attached `language-pack.zip` contains
  the existing Ukrainian/Bhojpuri teaching example: translations are partial and
  unreviewed. Install ZIPs through the language-pack settings; built-in languages
  are already included in the application.
- Size presets support Fullscreen, nine single-layer Quarter positions, two-layer
  halves, four quarters for larger selections, X/Y tiling, and Portrait/Landscape.
  Overflow repeats positions. Crop presets trim centered 4:3, 16:9 or 16:10 borders
  and resize the box; matching ratios do nothing. Enter finishes crop/mask editing.
- Layer and viewport menus offer quick layer creation and Move up/down. Wider folder
  gutters and a larger No folder target make dragging layers out easier.
- Matching import/export toolbar icons open the existing workflows. Mapping Load
  no longer collapses the window; solid scrollbars expose overflowing layer lists.
- Mask snapping includes visible-area centers. Layer borders can be disabled
  independently, including outer borders of moving layers.
- Aquilon rectangular-mask transfers support Layer/Source origins and both sizing
  strategies with preflight, ordering and readback checks. Emulator coverage is
  not physical-output acceptance; Cut & Fill and explicit fit modes remain separate.

Use a portable bundle for the application, icons and launcher helper. Canonical
`.tgz` archives are available for cargo-binstall; raw binaries are also provided.
Theme packs are separate installable ZIP assets, not application bundles. Theme
notices are included in the packs; game-inspired palettes contain no game assets.

Settings version 15 migrates versions 1–14 and adds installed-theme choices.
Project files remain version 18. Existing preferences and projects are preserved;
older application versions may reject newer settings.

Formatting, both Clippy configurations, all required Rust test configurations,
rustdoc and the pinned manual build passed. Whole-application line coverage is
92.14%. Build recipes and checksums accompany the downloads. Cross compilation
and package checks do not replace native Windows/macOS runtime acceptance.
