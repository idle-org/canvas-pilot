# Canvas Pilot v0.10.0-rc.16

This release candidate concentrates on making device transfers resilient and crop
editing predictable when layouts come from a switcher.

- Send review lists valid and skipped mappings explicitly, can send the valid
  subset, and offers deliberate resolution conversion without changing the saved
  project. Temporary readback failures retry without repeating writes or TAKE.
- Midra and Aquilon input changes adapt layer source dimensions while preserving
  the outer box and framing. Cropped Midra inputs use their processed dimensions
  without applying input crop twice.
- Exact and device-rounded fits loaded from Midra become normal Smart crops.
  Letterboxed, overflowing and stretched fits remain advanced Edge crops.
- Advanced fits have a green, mask-like edge helper. The image stays still while
  an edge is dragged and refits on release. Context-menu and Crop-property actions
  convert losslessly between Smart and Edge crop when the framing is representable.
- Enabling a configured input preview requests its first still immediately. Follow
  input and independent preview assignments report resolution and aspect mismatches
  without silently changing routing.

Use a portable bundle for the application, icons and launcher helper. Canonical
`.tgz` archives are available for cargo-binstall; raw binaries are also provided.
The separate `classic-themes.zip` and `video-game-themes.zip` assets install the
17 distributed example themes in two bounded collections. `language-pack.zip` is
the format-2, revision-1 Ukrainian/Bhojpuri teaching example; those translations
remain partial and unreviewed. Theme notices are included in each theme pack, and
game-inspired palettes contain no game assets.

Project schema 20 and settings schema 15 are unchanged from the first 0.10 release
candidate. Existing saved explicit fits remain explicit; exact-fit normalization
applies when importing device geometry. Aquilon shared crop and aspect-correction
restrictions remain, and advanced fit sends continue to follow each adapter's
documented support boundary.

Formatting, both Clippy configurations, all required Rust test configurations,
rustdoc, the pinned manual build, theme-pack byte validation and the coverage gate
passed. Whole-application line coverage is 91.65%. Read-only checks against an
Eikos 4K on firmware 3.3.10 confirmed the rounded-fit case used by regression
coverage. These observations and emulator tests are not physical-output acceptance;
native Windows and macOS runtime acceptance remains outstanding.
