# Canvas Pilot v0.9.18 — Aquilon model range and editor improvements

This release collects the changes since v0.8.0.

## Highlights

- All eleven standalone Aquilon models are recognized: RS alpha, RS1–RS6,
  Cmini, C, C+ and Cmax. Exact HTTP/AWJ model matching is preserved.
- All numeric Aquilon firmware versions may attempt connection. Versions outside
  6.2.x display a warning that backward compatibility is not guaranteed.
  Incompatible protocol fields stop transfers explicitly; older protocol
  implementations and linked systems remain unsupported. Only Cmax 6.2.79 has
  recorded emulator acceptance, not physical-output acceptance.
- Layer- and source-relative blanking masks, mask-edge snapping, crop/mask editing
  guides and a context-menu mask reset improve layout editing.
- Runtime language packs can be installed, updated by revision and removed in
  Settings. Additional language previews include Portuguese, Nepali, Thai, Hindi
  and Toki Pona; translations remain subject to linguistic review.
- Simplified menus and corrected hover outlines, project language restoration
  and crop guides. Feature-recording recipes document the showcase workflow.

## Compatibility

Projects now use schema 18, settings schema 14 and layer clipboard schema 3.
Supported older files migrate through the normal loader. Older applications may
reject newer formats; preserve originals when exchanging projects.
Default release builds retain the vendor codecs. Illustrator conversion still
requires the external VectorCraft converter. Credentials are never saved in projects.

## Validation and limits

The source passed 464 default-feature tests and 458 tests in each restricted
configuration, formatting, Clippy, rustdoc and the pinned manual build.
Whole-application line coverage is 91.70%. Aquilon model/firmware expansion has
synthetic regression coverage; it does not establish compatibility with every
historical firmware release or physical output.

The Linux release binary passed an isolated GUI startup/render check with an empty
application log. All 26 Python helper tests passed.

Cross compilation and archive checks do not establish native Windows/macOS GUI
behavior. Native runtime acceptance for those platforms remains outstanding.
